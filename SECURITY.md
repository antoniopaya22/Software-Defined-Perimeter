# Security Policy

This repository is a research lab for the Software-Defined Perimeter (SDP) framework and is not intended for production use. See the warning in the [README](README.md).

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. Do not open a public issue.

Include the affected component (controller, gateway, client, database or Compose setup), steps to reproduce and the impact you observed.

## Scope

- Configuration, scripts and Compose setup in this repository: in scope.
- Upstream components, [waverleylabs/SDPController](https://github.com/waverleylabs/SDPController) and [waverleylabs/fwknop](https://github.com/waverleylabs/fwknop): please also report to their maintainers.
- Egida: report in [Egida-Kassandra/egida](https://github.com/Egida-Kassandra/egida).
